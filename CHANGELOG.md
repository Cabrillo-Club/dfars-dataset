# Changelog

All notable changes to this dataset will be documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/) for the dataset structure.

## [1.0.0] — 2026-04-25

Initial public release.

### Added
- 30 DFARS clauses across 5 categories (cybersecurity, supply-chain, general, intellectual-property, small-business)
- JSON Schema (Draft 07) for the clause record shape
- Multiple distribution formats: aggregate JSON, compact JSON, CSV, per-clause JSON, lightweight index JSON
- GitHub Actions CI for schema validation, consistency, and lint
- CC-BY-4.0 license
- Cross-references to NIST 800-171 controls for every cybersecurity clause

### Clauses included

**Cybersecurity (7)**: 252.204-7008, 252.204-7009, 252.204-7012, 252.204-7019, 252.204-7020, 252.204-7021, 252.239-7010

**Supply chain (7)**: 252.204-7018, 252.211-7003, 252.225-7001, 252.225-7002, 252.239-7018, 252.246-7007, 252.246-7008

**General (7)**: 252.204-7000, 252.215-7002, 252.232-7003, 252.232-7006, 252.237-7010, 252.242-7005, 252.247-7023

**Intellectual property (6)**: 252.227-7013, 252.227-7014, 252.227-7015, 252.227-7017, 252.227-7018, 252.227-7019
